## ✨ Features

- **Real-Time CPU Telemetry:** Live core utilization, clock speeds, and active thread processing diagnostics.
- **Memory (RAM) Optimization:** Real-time physical allocation, swap memory buffer, and cache metrics.
- **GPU Activity Monitoring:** Graphics processor load, dedicated VRAM utilization, and rendering statistics.
- **Disk I/O Throughput:** Real-time read/write disk activity and storage capacity indicators.
- **Network Telemetry:** Live bandwidth monitoring displaying active upload/download speeds.
- **Minimal Resource Footprint:** Engineered to run continuously with near-zero background overhead.

## 🚀 Installation & Usage

### Option 1: Microsoft Store (Recommended)
Download directly from the [Microsoft Store](https://apps.microsoft.com/detail/9P9J9TFQ00HT?hl=en-us&gl=IN).

### Option 2: Run from Source
```bash
# Clone the repository
git clone https://github.com/jaideepkrishna2008-ui/Smart-system-monitor.git

# Navigate to project directory
cd Smart-system-monitor

# Run the monitor
python Smartmonitor.pyw
```
